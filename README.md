# andrews-curtis-solver

Search and learning tools for the **SAIR Andrews–Curtis Conjecture (ACC) Challenge** (Caltech / SAIR Foundation, 2026):
find short sequences of Andrews–Curtis moves that trivialise balanced presentations of the trivial group.

> **This is not a proof or disproof of the Andrews–Curtis conjecture.** It is a solver for the challenge's
> Discovery track plus partial, computer-verified results drafted for the Proof track.

## What's here

| Folder | Contents |
| :-- | :-- |
| `solver/` | C++ solver (`acs.cpp`): exact BFS "ball" of all states up to length 16/17 (129M / 514M states), cost-bucketed macro beam search, lookahead and power macros, cross-path splicing, waypoint restarts ("rebeam"), Stable-AC endpoints, bidirectional window shortcuts, GS class-distance oracle. Python pipeline: official-verifier checking (`check.py`), target selection (`tools.py`), SAIR API client (`sair.py`), campaign/focus loops, cloud sync. `README_EXPERIMENTS.md` logs every experiment, including the negative ones. |
| `value-model-study/` | Why learned value functions collapse onto a length proxy, and six training fixes (ablation). |
| `guide-learning/` | Expert-iteration attempts: search-labelled sibling states, guide training, GPU scoring server for the solver. |
| `selfplay/` | AlphaZero-style prototype: policy+value network, PUCT MCTS, imitation bootstrap, curriculum self-play. |
| `proof-track/` | Two **draft** Proof-track write-ups (not yet independently peer-checked): an exhaustive classification of rank-2 trivial-group presentations up to total length 14 (reducing AC at length ≤ 14 to six presentations) and 15–16, and length-bounded non-reachability + class reductions for the 550 open Miller–Schupp instances. Certificate files are regenerated by the included scripts. |

## Status (September 2026)

Team `nahom` reached **10th (AC)** and **9th (Stable AC)** on the public leaderboards. Our best paths are typically
about 2× the leaders' record lengths on longer instances; the experiment log documents what did and did not close
that gap.

Solution paths are intentionally **not** published during the competition.

## Building

    clang++ -O3 -march=native -std=c++17 -pthread solver/acs.cpp -o acs
    ./acs ball --cap 16 --out ball16.bin          # ~90 s, ~3 GB RAM
    python3 solver/prep.py                        # needs the official challenge repo checked out next to it

Scripts contain absolute paths from the original machine (`~/acc/...`); adjust them for your setup.
